# AskYard Rep — Chrome toolbar

Load unpacked. Search a name. See the meter.

This is the Ahrefs move: the site is the desk, the toolbar is how you check yourself in one click. Public AskYard votes plus Hacker News hits. A lookup, not a verdict. No roast wall.

## Install

1. Chrome → `chrome://extensions`
2. Developer mode on
3. Load unpacked
4. Pick this `extension` folder (from the live site copy, or `askyard/public/extension` in git)

The popup calls `GET https://askyard.firstdeploy.ai/api/rep?q=`. If you opened `popup.html` on the AskYard site itself, it uses that origin.

Then buy the lights at [marquee.firstdeploy.ai](https://marquee.firstdeploy.ai/) if you want the paid crown. You type the bid.
