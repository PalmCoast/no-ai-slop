# Link Fest brand

Link Fest uses the IndexMe.lol brand. The tokens below were read from the live desk stylesheet.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#10120f` | Hero, wordmark field, theme color |
| Paper | `#f4f2e9` | Page background |
| White | `#fffef9` | Cards |
| Acid | `#d8ff36` | Mark, primary button, pass state |
| Mint | `#a8ffd0` | Linked status |
| Orange | `#ff7657` | Live dot, failed checks |

## Type

- Manrope for the page
- DM Mono for eyebrows, hosts, and status words

## Mark

Acid circle, ink globe, wordmark `INDEXME` with `.LOL` in muted type. The fest name sits in the eyebrow, not in a second logo.

## Voice

Say the link, the price, and the page that wrote the idea. A follow link with the name visible is the share. The original stays on the source page.
